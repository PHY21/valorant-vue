# VALORANT Atlas · Vue 3 求职展示版

用户选择：直接完成独立的 Vue 3 求职展示版。原 PHP 目录、XAMPP 站点和 PHY21/valorant-web 仓库不改动；原提交 faea815 已归档备份。

实现 Vue 3 + Vite + Vue Router + Pinia 单页应用。复用提交版 SQL 的选手、战队、赛事、特工、成绩和关联数据，排除用户、评论、日志。示例数据不是实时赛事数据。

页面：首页概览、可组合筛选的选手库、选手详情、战队与赛事浏览/详情、特工库、排行榜、双选手对比、收藏夹、项目说明。收藏及评论仅存当前浏览器，无真实账号或密码，明确标注。细节页支持无数据状态；未知路由提供返回入口。

视觉：暖白底、深墨色文字、珊瑚红电竞强调色；侧栏导航、编辑式大标题、选手照片、清晰表格、简洁数据条形图。桌面多列，手机折叠为单列，键盘可操作，图片缺失显示占位。

考虑过完整 Vue + 后端云数据库方案，需要额外运行维护；本次选择静态公开演示，突出岗位需要的前端能力。作品说明区和 README 说明实现边界，附面试讲解，不夸大经验。

验收：构建和行为测试通过；搜索筛选、路由详情、对比、收藏持久化、评论新增删除工作；移动端不横向溢出；线上 URL 可公开访问；原项目哈希与工作区保持一致。
