## 设计与取舍

延续 Vue 3 + Supabase，使用邮箱密码认证，并验证邮箱所有权。通过邮件数字验证码完成注册确认和密码重置，避免 GitHub Pages hash 路由与邮件链接冲突，也支持跨设备输入验证码。注册、登录、验证、找回是公开页面；其余路由必须登录。密码重置会话只能完成改密，完成后退出重新登录。

图鉴从公开静态部署资源改为 Supabase 中只读 JSON；匿名角色不能读取，已验证真实邮箱账号可以读取。评价/昵称同样要求此资格，作者写权限继续生效。旧用户名账号记录保留，无法进入新版。公开源码/历史课程样本不是保密资料。

邮件：用户选择 QQ/163 SMTP，地址待提供，授权码由用户在 Supabase 表单自行填写，不写进代码、仓库或聊天记录。未完成邮件配置及实际收信验收前，不声称可用。
