# 在线账号功能

用户已选择真实在线账号，可跨设备登录。只改独立 Vue 仓库；原 PHP 作业不变。

## 实施顺序

1. 认证服务：Supabase 邮箱密码注册、登录、退出、会话恢复；测试输入校验、服务错误、确认邮箱状态、安全站内返回地址。密码不存入业务存储。
2. Vue 页面：导航账号入口、注册/登录/账号页、邮箱确认回调；加载和错误状态、手机布局、登录后回原页面。
3. 评价：登录后公开发表，昵称来自账号；Postgres RLS 限制只能删除自己的评价。旧本地评价仍作为私有历史保留，不自动上传。收藏继续明确标注本地保存。
4. 部署准备：迁移 SQL、环境变量示例、Pages 构建变量、设置与验收文档。
5. 单元测试、构建、浏览器验收、一次独立代码审查。连接后端后再进行真实双账号越权和跨设备验收、上线。
