# Vue demo Implementation Plan

> For agentic workers: Use superpowers:executing-plans to implement task-by-task.

**Goal:** Publish an independently maintained Vue 3 recruitment demo while preserving PHP coursework.
**Architecture:** Static JSON from submission SQL, Vue route views, Pinia local state, shared data utility functions.
**Tech Stack:** Vue 3, Vite, Vue Router, Pinia, Node test runner.
**Spec:** ../../design.md

## Global Constraints
- No changes to original PHP repository or runtime; no private user/comment export.
- Label local-only persistence and non-live dataset accurately.
- Public mobile-friendly demo and source repository.

## Review Focus
- Empty or malformed persisted state must not crash pages.
- Unknown detail IDs and empty filters must show recovery actions.
- Same-player comparison and missing stats must not produce misleading values.
- Browser refresh/deep links must work under a repository URL.
- Long titles and small screens must stay readable without overflow.
