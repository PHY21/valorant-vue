# 3 分钟演示路线

1. 首页：介绍从 PHP 课程项目迁移到 Vue 3 的动机，说明原项目独立保留。
2. 选手图鉴：搜索 ZmjjKK，切换赛区和定位，展示无结果提示与重置。观察地址栏保存查询参数。
3. 详情页：浏览赛事记录，收藏选手，切换收藏夹后刷新。演示本地评价新增和删除，主动说明并非真实在线评论。
4. 选手对比：选择两名选手，对照 Rating、ACS、K/D 和收录场次。解释加权均值及样本不同时的局限。
5. 手机布局：打开窄屏导航，展示卡片重排与表格横向滚动。
6. GitHub：指出 Vue 组件、Pinia store、纯函数测试以及 Actions 部署记录。

# 必须能解释的代码

- `src/main.js`：Hash 路由为何适合静态部署，动态 import 如何拆分路由包。
- `src/stores/catalog.js`：computed 与 watch 的职责，为什么保存操作需要 try/catch。
- `src/lib/domain.js`：多条件 filter 的组合逻辑；加权均值与普通平均值/最大值的区别；缺失数据为什么显示“—”。
- `src/components/PlayerCard.vue`：props、组件复用、收藏状态来自哪里。
- `src/views/Explore.vue`：响应式筛选、路由查询同步、分页和无结果状态。
- `src/style.css`：Grid、Flex、媒体查询以及移动导航隐藏时的可访问性。

# 如实介绍项目

可描述为“基于原有 PHP 数据库课程项目升级并部署 Vue 3 前端交互 Demo，包含筛选、路由、收藏、数据对比和响应式适配”。请先学习代码并实际演示；如果被问到开发过程，如实说明使用了 AI 辅助。不要说自己已经实现在线鉴权、服务器评论、实时赛事 API、真实用户增长或未经测量的性能提升。

后续可学习：TypeScript、组件测试、真实 API 请求、后端鉴权与数据库服务；这些是后续计划，不是当前已完成能力。
